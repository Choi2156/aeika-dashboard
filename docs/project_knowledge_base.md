## 1. 간트 차트 겹침 일정 레인 전환 기법 (`lane_override`)

### 1.1 개요 및 목적
- **문제 상황**: 동일한 타입(예: `오프라인이벤트` vs `오프라인이벤트`)의 일정이 동일한 기간 내에 겹치는 경우, 간트 차트에서 같은 세로 레인(Lane)에 중첩되어 시각적 혼선이 발생하거나 클릭이 어려울 수 있습니다.
- **해결 원칙**: 이벤트의 본래 데이터 속성(`type: "오프라인이벤트"`, 📍 아이콘, 리스트 뷰 분류, 상세 모달 정보 등)은 **100% 원본 그대로 유지**하면서, 간트 차트의 **세로 위치(레인)만 비어있는 상단 라인(예: `공식방송` 라인)으로 이동**시켜 렌더링합니다.

### 1.2 엔진 구현 방식 (`src/views/GanttView.jsx`)
`GanttView.jsx`의 이벤트 레인 연산부에 `lane_override` 렌더링 힌트 탐지 로직이 탑재되어 있습니다:

```javascript
// 해당 게임의 동적 레인 맵에서 본 이벤트 타입의 인덱스 추적 (lane_override 속성이 있으면 해당 레인 위치 적용)
const lanes = gameLanesMap[gameName] || ['전반업데이트', '후반업데이트', '공식방송', '오프라인이벤트'];
const targetType = ev.lane_override || ev.type;
const laneIndex = lanes.indexOf(targetType) !== -1 ? lanes.indexOf(targetType) : 0;
const topPos = `${laneIndex * 36 + 6}px`;
```

### 1.3 사용 방법 (`public/data/schedule_updates.json`)
겹치는 일정 중 이동하고자 하는 이벤트 객체에 `"lane_override"` 속성을 추가하고 대상 레인 명칭을 지정합니다.

- **지정 가능 레인 명칭**: `"전반업데이트"`, `"후반업데이트"`, `"공식방송"`, `"오프라인이벤트"`

#### 적용 예시 (`schedule_updates.json`):
```json
{
  "id": "EVT_WW_20260829_0001",
  "game": "명조",
  "version": "콜라보",
  "type": "오프라인이벤트",
  "title": "명조 월드 투어 ｢To the New World｣ 콘서트",
  "date": "2026-08-29",
  "end_date": "2026-08-29",
  "is_fixed": true,
  "lane_override": "공식방송",
  "detail": "...",
  "custom_img": "..."
}
```

### 1.4 적용 효과
- **간트 차트 뷰**: 📍 핀 모양이 달린 오프라인 이벤트 고유의 디자인 바 형태를 유지한 채, 세로 위치만 상단 **방송 라인(위에서 3번째 라인)** 위치로 한 칸 올라가 렌더링되므로 겹침이 사라집니다.
- **리스트 뷰 / 상세 모달 / 데이터 파이프라인**: `type: "오프라인이벤트"` 원본을 유지하므로 어떠한 데이터 왜곡이나 부작용도 일으키지 않습니다.
