## 3. 👥 사용자 충성도 및 행동 패턴 정밀 분석

```
└───────────────────────────────────────┴─────────────────────────────────┘
```

### 1. 신규 유입 vs 단골 충성도 균형
- **신규 방문자 수 (401명 / 79.4%)**: 최근 28일간 사이트를 처음 방문한 신규 유저가 401명에 달합니다. 채널 영상의 설명/댓글 링크가 완전히 죽지 않고 꾸준히 새로운 시청자를 대시보드로 실어나르고 있습니다.
- **단골 재방문율 (일평균 41.9%)**: 유틸리티 툴에서 재방문 비율이 40%를 상회한다는 것은 **"한 번 방문한 뒤 브라우저 북마크에 등록해두고 정기적으로 일정을 보러 오는 코어 유저군이 최소 수십 명 규모로 안착했음"**을 뜻합니다.

### 2. 체류 시간(24초)에 대한 올바른 해석
- 일부 웹사이트 분석에서는 "체류 시간 1분 미만"을 부정적으로 보기도 하지만, **대시보드는 검색 포털의 날씨/증시 위젯과 같은 유틸리티**입니다.
- 유저의 목표는 **"오늘 무슨 이벤트가 열렸는지 / 언제 끝나는지"** 단 하나이며, 사이트가 직관적이고 군더더기 없이 정보를 제공할수록 체류 시간은 15초 - 30초 선에서 짧고 간결하게 종료됩니다.
- 따라서 현 시점의 평균 24초 체류 시간은 사이트가 **"목적 지향적 정보 전달에 매우 최적화되어 있다"**는 긍정적 지표로 해석하는 것이 정확합니다.

### 3. 스크롤 심도와 콘텐츠 시선 흐름
- **스크롤 이벤트 841회 (사용자 350명 / 70.4% 도달)**:
  - 10명 중 7명은 사이트 접속 후 마우스 휠이나 모바일 터치로 스크롤을 내립니다.
  - 이는 최상단 간트차트만 보고 끄는 것이 아니라, 화면 중하단의 **[상세 일정 리스트] 및 [추천 유튜브 영상] 영역까지 시선이 안정적으로 도달**하고 있음을 나타냅니다.

## 4. 🔄 유튜브 채널 ↔ 대시보드 양방향 트래픽 순환 구조 진단

```
┌─────────────────────────┐               ┌─────────────────────────┐
│   YouTube 애이카 채널    │  ──────(A)───▶  │  서브컬처 일정 대시보드  │
│ (구독자 1,003명 / 쇼츠) │               │   (월 505명 순방문자)   │
└─────────────────────────┘  ◀───(B)────── └─────────────────────────┘
```

### (A) 유튜브 ➔ 대시보드 유입 (검증 완료: 매우 강력)
- **현황:** 채널 영상의 고정 댓글 링크는 현재 대시보드의 유일무이한 핵심 유입 파이프라인입니다.
- **성적:** 28일간 505명의 MAU를 만들어냈으며, 특히 신규 영상 업로드 시 트래픽이 3배 이상 폭증하는 등 완벽한 연동 효과를 발휘하고 있습니다.
- **개선 제언:** 현재는 모든 영상에 동일한 루트 도메인(`https://aeika.site`)이 걸려 있어 영상별 유입 효율을 개별 분리하기 어렵습니다. 향후 단축 링크나 UTM 파라미터(`?utm_source=youtube&utm_campaign=august_update`) 도입 시 어떤 영상이 사이트 유입을 가장 많이 유발하는지 100% 추적 가능해집니다.

### (B) 대시보드 ➔ 유튜브 재유입 (전환 추적 체계 신설 완료)
- **현황:** 대시보드 하단의 추천 영상(쇼츠 6종, 스토리 풀버전, 롱폼 클립)을 통해 유저가 다시 유튜브 채널로 건너가는 구조입니다.
- **기존 한계:** v1.2.3까지는 카드 클릭 이벤트가 GA4에 세부 태깅되지 않아 '기본 클릭(51회)' 중 영상 이동이 몇 건인지 정량적으로 분리할 수 없었습니다.
- **v1.2.4 조치 완료:** 이번 v1.2.4 업데이트에서 `recommended_video_click` 커스텀 이벤트를 신설 탑재했습니다. **금일(2026-09-06)부터는 대시보드에서 추천 영상을 클릭하여 채널로 건너간 실측 전환 수가 실시간 집계**됩니다.
