## 📌 서비스 소개

본 대시보드는 여러 게임에 분산된 버전 업데이트, 공식 특별 방송, 픽업 기간 및 오프라인 행사 일정을 단일 페이지에서 확인할 수 있도록 제작된 비공식 팬 프로젝트입니다.

일정 타임라인과 함께 **애이카 아카이브** 유튜브 채널과 연계하여 각 게임별 스토리 풀버전 영상, 하이라이트 영상 및 추천 쇼츠를 제공합니다.

## 📋 화면 구성 및 주요 기능

```
┌────────────────────────────────────────────────────────────────────────┐
│ 상단 롤링 공지 배너 (공지사항 알림)                                     │
├────────────────────────────────────────────────────────────────────────┤
│ 게임 필터바 (게임 선택 / 뷰 모드 전환 / 테마 설정)                      │
├────────────────────────────────────────────────────────────────────────┤
│ 메인 일정 타임라인 (간트 차트 뷰 / 리스트 뷰)                           │
├──────────────────────────────────┬─────────────────────────────────────┤
│ 다가오는 공식 방송 및 오프라인 행사 │ 추천 인기 쇼츠 (10개 풀 셔플)       │
│ 스토리 풀버전 / 롱폼 추천 영상   │ 공지사항 목록 (패치 / 일반 / 홍보)  │
└──────────────────────────────────┴─────────────────────────────────────┘
```

### 1. 일정 타임라인
- **간트 차트 뷰 (PC)**: 타임라인 그리드를 통해 각 게임별 전/후반 버전 기간, 방송일, 행사 일정을 가로 막대로 시각화
- **리스트 뷰 (모바일)**: 모바일 화면에 최적화된 카드 목록 형태의 일정 뷰
- **확정 및 예상 일정**: 공식 발표된 확정 일정과 이전 패치 주기를 기반으로 한 예상 일정을 구분하여 표시

### 2. 추천 영상 연계
- **스토리 풀버전**: 게임별 메인 스토리 컷편집 풀버전 영상 제공
- **롱폼 추천 영상**: 단일 게임 대상 하이라이트 및 클립 영상 제공
- **추천 쇼츠 셔플**: 게임별 10개의 쇼츠 풀에서 새로고침 시 무작위 셔플을 통해 6개 선별 노출

### 3. 공지사항 알림
- **상단 롤링 배너**: 주요 공지 텍스트를 상단에 슬라이드로 노출
- **하단 공지 위젯 및 상세 팝업**: 최근 공지 리스트 및 전체 공지 목록/본문/이미지/링크 확인
- **3대 카테고리 & 중요 구분**: `패치`, `일반`, `홍보` 카테고리 태그 및 중요(`🔥`) 공지 표시

### 4. 사용자 편의 기능
- 게임별 표시 여부를 켜고 끌 수 있는 필터 기능
- 다크 모드 / 라이트 모드 테마 전환
- 로컬 스토리지를 활용한 사용자 설정 저장 및 복원
